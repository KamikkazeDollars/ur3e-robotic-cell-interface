<objective>
Close G-03-6: give the rail rig, the workbench and the floor three genuinely distinct colors, and make
the drift that caused them to collide impossible to repeat.

Purpose: the rail rig and the workbench are currently painted with the identical hex literal, declared
three separate times in three separate components — one of which carries a comment admitting it was
copied from another. The value itself is orphaned: it belongs to the light theme that the
Quick-260815-3cn retheme replaced, and it appears nowhere in the current design-token palette. Fixing
only the two colors would leave the mechanism that produced the collision fully intact. This plan
replaces three disconnected copies with one token-backed module and an automated gate that fails when
any two scene surfaces converge again.
Output: `src/scene/scene-palette.ts` plus its anti-drift test, three new `--ui-scene-*` tokens, and
four scene components rewired to read from the palette instead of declaring their own colors.
</objective>

```typescript
// src/scene/scene-palette.ts (new — this plan)
export interface SceneTone {
  /** The `--ui-*` custom property in src/index.css this hex mirrors. */
  readonly token: string
  /** The literal three.js materials are given. Must equal the token's declared value. */
  readonly hex: string
}

export const SCENE_PALETTE: {
  readonly background: SceneTone
  readonly floor: SceneTone
  readonly workbench: SceneTone
  readonly rail: SceneTone
  readonly navCubeFace: SceneTone
  readonly navCubeStroke: SceneTone
  readonly navCubeHover: SceneTone
  readonly navCubeText: SceneTone
}

/** WCAG relative luminance of a `#rrggbb` string, 0..1. Exported so plan 03-05's
 *  marker-readability test reuses this exact implementation rather than writing a second one. */
export function relativeLuminance(hex: string): number

/** WCAG contrast ratio between two `#rrggbb` strings, 1..21. */
export function contrastRatio(a: string, b: string): number

/** The pairwise separation every distinct scene surface must clear. */
export const MIN_SURFACE_CONTRAST: number
```

warm cutting line and the gray rapid line drawn on top of it both stay legible, rail lightest so the

Declare `SCENE_PALETTE` with `as const satisfies Record<string, SceneTone>` so the literal types are
preserved and a malformed entry is a compile error.

Export `relativeLuminance(hex: string): number` implementing the standard WCAG formula: parse the three
byte channels from the `#rrggbb` string, divide each by 255, linearize each channel (channels at or
below 0.03928 divide by 12.92; above that, apply `((c + 0.055) / 1.055) ** 2.4`), then weight the
linearized channels 0.2126 / 0.7152 / 0.0722 and sum. Throw a descriptive `Error` on any input that is
not a six-digit `#rrggbb` string, so a malformed palette entry fails loudly instead of silently
producing `NaN`.

Export `contrastRatio(a: string, b: string): number` as `(lighter + 0.05) / (darker + 0.05)` over the
two relative luminances, ordering the operands internally so the function is symmetric.

Export `MIN_SURFACE_CONTRAST = 1.5`, with a comment recording that this is the floor the three
structural surface tones must clear against each other, that the chosen tones clear it with roughly
25% headroom (the floor/bench and bench/rail pairs both land near 1.9, the floor/rail pair near 3.7),
and that the threshold deliberately governs only the three structural surfaces — the background is
asserted distinct by value alone, because no two near-black tones can clear a meaningful contrast
ratio and forcing one would push the ground plane out of the dark theme.
