<objective>
Close the two remaining cosmetic UAT gaps from the developer's Phase 2 sign-off (02-UAT.md, Tests 1 and
6): the toolpath's lines read as too thin with no way to see where the job starts or ends (G-02-03), and
the navigation cube's axis triad is fully hidden behind its opaque faces (G-02-04).

**Scope note (G-02-03).** This phase's toolpath is one continuous parsed path, not yet split into a named
operations list — that structure (per-operation start/end markers) is ROADMAP Phase 6 ("Operations Tree +
Mill Engagement Coloring"). This plan marks the *overall* toolpath's single start and single end point
only; granular per-operation markers remain out of scope here, exactly as 02-UAT.md's root-cause note for
G-02-03 records.

**Scope note (G-02-04).** `NavCube.tsx` is technically a Phase 1 file (the nav cube itself is SCENE-03),
not Phase 2 output, but the developer reported it alongside the Phase 2 items in the same UAT session, so
it is closed here rather than opening a separate phase-1 gap-closure cycle for one prop.

Purpose: both defects are purely cosmetic (no data or logic is wrong) but directly affect whether the
demo reads as polished — the phase's core value is the visual toolpath render itself.
Output: thicker, clearly bounded toolpath lines and a nav cube whose axis triad is actually visible.
</objective>
