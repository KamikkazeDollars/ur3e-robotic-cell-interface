<objective>
Build the project's kinematics core: the officially-sourced UR3e DH parameter table, a hand-written standard-DH forward-kinematics chain that also accepts the 7th-axis rail position, the 7th-axis rail's travel geometry, and the Vitest assertions that prove all of it against externally-computed reference values.

Purpose: PITFALLS.md Pitfall 1 is the single highest-risk correctness item in this entire project — a DH table with the wrong convention produces a robot that looks completely plausible while placing the TCP in the wrong place, and every later phase (Phase 3 IK, Phase 3 trajectory compile, Phase 5 telemetry, Phase 8 calibration preview) is built on top of this math. It must be proven in isolation, before any 3D rendering can be trusted to "look right".

Output: `src/kinematics/` — a framework-free, directly unit-testable module, green against the reference pose, ready for plan 01-03 to pose the rendered robot from and for Phase 3 to build inverse kinematics on.
