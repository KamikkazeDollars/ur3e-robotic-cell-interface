<objective>
Stand up the project's walking skeleton: a real Vite + React + TypeScript + React-Three-Fiber application that renders an interactive, neutral-studio-lit 3D cell with working orbit/pan/zoom and a Fusion-360-style navigation cube — version-controlled on GitHub and served from a publicly reachable production URL that redeploys on every push.

Output: a running, deployed, orbitable 3D cell; the pinned dependency manifest; the Vitest harness that Phase 1's kinematics tests run under; and `01-SKELETON.md`'s architectural decisions made real.
</objective>
